POCKET TTS — DESIGN SHOWCASE
============================

A mockup of a next-generation on-device Android text-to-speech app with
voice cloning, audio editing before cloning, and an extended feature set.

WHAT IS IN HERE
---------------
  START-HERE.txt   This file.
  README.md        Full notes: the feature ideas behind each screen and the
                   design-system mapping to the real app.
  build.mjs        Renders every screen to out/*.png  (node build.mjs)
  contact-sheet.mjs Renders out/contact-sheet.png — all screens on one page.
  src/             The mockup source:
                     tokens.css    colour + type tokens, mirrored from the
                                   app's PocketTheme.kt
                     base.css      component library (cards, buttons, sheets,
                                   sliders, waveforms, navigation dock)
                     lib.js        icon set, speech-waveform generator, helpers
                     screens-a.js  primary application screens
                     screens-b.js  sheets, dialogs and light-theme variants
  out/             The rendered deliverable:
                     29 screen PNGs, each 1080x2400 px (360x800 dp at 3x DPR)
                     contact-sheet.png — one-page overview of all screens
                     index.html    a live gallery of every screen

HOW TO VIEW IT
--------------
  Option A — the gallery (recommended)
    Open out/index.html in any desktop browser.

  Option B — the contact sheet
    Open out/contact-sheet.png. Everything on one page.

  Option C — the individual screens
    Open any PNG in out/. They are sized to drop straight into a README
    next to real app screenshots, at 3x device pixel ratio.

  Option D — on your phone
    Copy the whole folder to the device and open out/index.html in
    Chrome. The screens are 360x800 dp, so they scale cleanly.

HOW TO REBUILD
--------------
  Requires: Node 18+ and a `chromium` binary on PATH.
  No network access and no image assets are needed — every pixel is
  HTML/CSS/SVG.

    node build.mjs              # all 29 screens + out/index.html
    node build.mjs --only=10,27 # re-render just the matching screens
    node contact-sheet.mjs      # out/contact-sheet.png
